# 蛙蛙厨房 · 横屏手机网页试玩版

**在线试玩：** [https://tom040205.github.io/wawa-kitchen-mobile/](https://tom040205.github.io/wawa-kitchen-mobile/)

这是一个无需安装、可直接在手机浏览器打开的静态 Canvas 2D 小游戏。它保留了接单、取材料、限时制作、送到投喂台并获得奶蛋的循环；原 Unity 工程保持不变。

## 手机操作

本游戏按**手机横屏**设计。手机竖屏打开时，会显示横屏提示；点“尝试全屏横屏”后，浏览器会尝试请求全屏和横屏锁定。若手机浏览器不支持自动旋转，请手动将手机横过来。

横屏后，左侧虚拟摇杆负责移动，右侧圆按钮负责拿取或交付；也可以轻点厨房地面移动。左侧订单卡会列出材料，完成订单有 48 秒倒计时。桌面端支持方向键或 WASD 移动，并按 E、空格或 Enter 互动。

## 角色图片与素材

网页使用了你提供并授权公开使用的奶蛙、奶蛋图片。游戏直接读取这些原始 JPEG 文件，未覆盖原图；图片白底以画布混合方式融入场景。厨房、道具与界面由代码绘制，没有加入先前仅供本地试玩的网络梗图或音频。

## 本地运行

本目录没有外部运行依赖，可用任意静态网站托管，入口为 `index.html`。本地开发时运行：

```bash
python3 -m http.server 8080
```

然后访问 `http://localhost:8080`。

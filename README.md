# 蛙蛙厨房 · 手机网页试玩版

**在线试玩：** [https://tom040205.github.io/wawa-kitchen-mobile/](https://tom040205.github.io/wawa-kitchen-mobile/)（GitHub Pages 发布完成后生效）

这是为手机浏览器制作的轻量网页版本。它保留了 Unity 原型的核心循环——接单、取空杯与奶锅、收集配料、在倒计时结束前交付并赚取奶蛋——同时把触控摇杆、互动按钮和画面布局改为网页原生实现。Unity 2021 WebGL 在手机浏览器上的兼容性有限，因此此试玩版使用独立的 Canvas 2D 实现；原 Unity 工程保持不变。

## 手机操作

左下角虚拟摇杆移动奶蛙，右下角按钮拿取或交付；也可以轻点厨房地面向附近移动。顶部会显示配方、所需材料和 48 秒倒计时。按订单依次收集材料并走到“投喂台”交付。每单成功获得 1 颗奶蛋；最佳成绩保存在本机浏览器。桌面端保留方向键 / WASD 与 E、空格交互。

## 运行与发布

本版本没有外部依赖、服务器逻辑或第三方图片/声音文件。用静态 HTTP 网站托管本目录即可，入口为 `index.html`；本地开发时可运行：

```bash
python3 -m http.server 8080
```

然后访问 `http://localhost:8080`。此目录里的角色、道具、厨房与提示效果均由 Canvas 程序绘制；没有使用仅限私人本地试玩的网络梗图或音频素材。公共部署时，托管平台需将 `index.html` 作为默认首页。
